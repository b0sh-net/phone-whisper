# Privacy Policy for Audio To Text

Audio To Text is an Android utility that transcribes audio files shared via the "Share" menu.

## Data handling

Audio To Text is fully local: audio files and transcriptions are processed on-device and never leave your device. The app does not send audio or text to any remote service.

## Network usage

The only network activity is downloading speech recognition models from the sherpa-onnx release archives on GitHub, triggered explicitly from the model catalog inside the app. Model files are stored in the app's internal storage.

## API keys

Audio To Text does not use any API keys.

## Accessibility Service

Audio To Text does not use the Accessibility Service.

## Data collection

I do not run a backend for Audio To Text and do not collect user accounts, analytics, or uploaded recordings.
